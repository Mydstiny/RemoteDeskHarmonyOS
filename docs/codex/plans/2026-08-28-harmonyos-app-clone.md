# HarmonyOS 手机 / 平板应用分身实施计划

## 状态

- 类型：已实施，等待真机验收
- 实施日期：2026-08-28
- 实施基线：经用户明确授权，在当前 `codex/system-clipboard-activation-fix` 工作树继续实施；应用分身增量基线为 `8984f588e`

## 目标

在支持应用分身的 HarmonyOS 手机和平板上，为 RemoteDesk 提供“主应用 + 1 个分身”。两个实例可分别维护远程主机、凭据、密钥和会话；第一版优先保证身份与敏感数据隔离，不改变现有协议、加密和主应用云同步行为。

## 产品与安全决策

1. 使用系统 `appClone` 能力，`maxCount` 固定为 `1`；不自建容器，也不复用 PC/2in1 多窗口能力。
2. 主应用索引为 `0`，分身索引大于 `0`；业务统一通过一个只读上下文服务识别当前实例。
3. 第一版分身强制使用本地模式，不启用 Account Kit 登录，也不上传或拉取 AGC 云数据；主应用维持当前账号与云同步策略。
4. 主应用与分身不得共享连接记录、密码、SSH 私钥、TOTP、临时授权或运行时会话。系统剪贴板是设备级能力，因此分身禁用 RemoteDesk 的双向自动剪贴板桥接；用户在系统层主动复制粘贴仍遵循平台规则。
5. 在真机证明云端按分身索引可靠隔离前，不开放分身云同步。

## 实施范围

### 1. 系统能力与实例识别

- 在 `AppScope/app.json5` 声明 `multiAppModeType: "appClone"` 和 `maxCount: 1`。
- 增加应用分身上下文封装，集中读取 `getCurrentAppCloneIndex()`，禁止业务层散落判断。
- 在“数据与安全”设置中展示当前实例身份；分身明确标注“本地数据，不参与云同步”。

### 2. 数据和账号边界

- 审计 Preferences、RDB、Asset Store、文件、缓存和运行时单例，确认均使用当前应用实例的沙箱上下文。
- 在云同步入口、后台调度、手动同步和云设置入口统一阻断分身访问，采用默认拒绝策略。
- 主应用继续执行 Account Kit 登录、退出和令牌持久化；分身第一版不初始化 AGC Auth、不开放登录/退出或服务端撤权入口。
- 后续若开放分身账号能力，必须先完成主/分身交叉登录、退出与撤权矩阵，确认一个实例不会破坏另一个实例的会话或数据。

### 3. 远控与系统集成

- 验证 RDP、RustDesk、SSH/SFTP、VNC 和 Moonlight 在主应用与分身中可独立建立、恢复和终止会话。
- 验证通知、音频、文件选择授权、后台任务、网络切换和锁屏恢复不会串实例；验证分身不会自动读取系统剪贴板或把远端剪贴板写入系统剪贴板。
- 对双实例同时远控设置资源验收线，重点观察内存、解码、GPU、发热、电量和系统回收行为。

### 4. 测试与发布

- 至少覆盖一台支持应用分身的 HarmonyOS 手机和一台平板；记录系统版本、机型和分身入口可用性。
- 完成创建、升级、删除分身以及卸载主应用的生命周期测试。
- 增加实例识别、云同步拒绝和本地策略的单元测试；敏感数据隔离必须以真机结果验收。
- 通过项目规定的 ArkTS 测试编译、签名 HAP 构建、合规检查、差异检查和独立复核后再发布。

## 验收标准

1. 系统设置中可创建且只能创建一个 RemoteDesk 分身，桌面入口可明确区分。
2. 两个实例首次启动、权限、主机列表、凭据、密钥、TOTP 和用户设置互不影响。
3. 分身的自动、手动及后台云同步均不可执行，且 UI 不造成“已同步”的误导。
4. 删除分身只删除分身数据；主应用数据和会话保持完整。卸载主应用后的系统行为符合平台约定。
5. 任一实例登录、退出或取消授权，不得静默破坏另一实例的本地数据；令牌影响有明确验证结论。
6. 主应用与分身可分别建立远控会话；分身不启动自动剪贴板桥接；资源不足时能安全失败或被系统回收，不遗留后台任务和敏感状态。
7. 日志、遥测、通知和错误提示可以区分实例，但不得记录凭据、令牌或其他秘密。

## 风险与放行条件

| 风险 | 首版控制 | 放行条件 |
|---|---|---|
| AGC 云数据可能不按分身隔离 | 分身强制本地模式 | 真机与云端记录证明实例间完全隔离 |
| Account Kit 撤权可能跨实例生效 | 拆分本地退出与服务端撤权 | 主/分身交叉登录退出矩阵通过 |
| 双实例远控资源竞争 | 设置并发压力测试与安全失败标准 | 手机、平板各完成协议组合测试 |
| 厂商/机型不开放分身入口 | UI 不承诺所有设备可用 | 发布说明列明系统和机型依赖 |

## 回滚方案

- 下个版本移除 `appClone` 声明即可停止创建新分身；不设计应用内跨实例迁移或合并数据。
- 若上线后发现云同步或授权越界，立即保持/恢复分身本地模式并关闭相关入口，不删除用户本地数据。
- 所有策略变更应可独立回滚，不修改远控协议数据结构和现有主应用云数据格式。
