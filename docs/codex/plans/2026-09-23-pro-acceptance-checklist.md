# RemoteDesktop Pro 与远程 AI 验收清单

这份清单用于逐项验收当前 Pro 计划。每项都记录“通过 / 失败 / 未测试”和证据（截图、日志或订单号）。代码已完成的项目可以直接进入设备验收；标为“外部配置”的项目需要 AGC、AppGallery 或生产环境条件。

## 1. 验收前准备

- [ ] 记录构建版本、Git commit、设备型号、HarmonyOS 版本和屏幕字体/显示比例。
- [ ] Phone、Pad、PC 均安装同一 Debug/沙盒包，保留一份应用配置备份。
- [ ] 测试账号已登录；测试过程不在聊天中记录密码、PIN、验证码或私钥。
- [ ] 确认当前使用沙盒商品，页面明确显示不会产生真实扣费。
- [ ] 确认正式购买、正式 worker、生产签名和生产通知仍保持关闭。

## 2. Pro 购买、权益与恢复

- [ ] 未登录或鉴权失败时，Pro 功能显示受限状态，不能执行受保护动作。
- [ ] 登录成功后，商品列表显示正确的 Pro 商品、价格和周期。
- [ ] 沙盒购买成功后，权益立即变为有效，Pro 页面和受保护入口同步更新。
- [ ] 购买过程中取消、失败、重复点击和网络中断都能返回可重试状态，不崩溃、不重复扣款或重复发货。
- [ ] 强制结束并重启 App 后，权益可从本地缓存和服务端恢复。
- [ ] 在另一台设备登录同一账号，权益状态与购买设备一致；切换到其他账号后不能继承前一账号权益。
- [ ] 沙盒退款/撤销后，权益在刷新、重启和重新登录后收回。
- [ ] 订单、权益、幂等键和错误码可在验单日志中对应，敏感值已脱敏。
- [ ] worker 手动执行结果为 HTTP 业务成功且待处理订单为 0；自动定时触发保持关闭，直到单独批准。

## 3. Pro 标识与各协议页面

- [ ] 所有 Pro 功能入口右上角显示统一的幻彩 `Pro` 标识。
- [ ] Pro 标识在浅色、深色、大字体和横竖屏下不遮挡标题、按钮或返回控件。
- [ ] RDP、RustDesk、SSH/SFTP、VNC 与远程 AI 的添加、编辑、设置、删除、保存和取消操作具有一致的触控尺寸、间距、错误提示和返回行为。
- [ ] 免费状态下点击受限入口显示清晰的升级/登录提示，返回后表单内容不丢失。
- [ ] AI 主机卡片、拖拽预览和分组卡片使用统一协议色；卡片状态不会把“已配置”误写成“已在线”。

## 4. 远程 AI（Codex 与 DSH）

### 配置与配对

- [ ] 从经典添加入口和现代添加入口都能添加 AI 主机。
- [ ] Codex 与 DSH 后端可分别选择、编辑、删除并保存；默认端口和手工端口校验正确。
- [ ] 邀请文本粘贴、解析、过期、重复使用、退出后台清除和账号切换行为符合预期。
- [ ] mTLS 配对成功后，凭据只保存在本机；地址或证书变化会要求重新配对。
- [ ] 未配对、证书不匹配、连接拒绝、超时、服务端错误和 Pro 失效均显示可操作的错误，不崩溃。

### 会话与控制

- [ ] 成功创建项目并显示历史记录、恢复项目和当前输入状态。
- [ ] 文本流式输出、连接中断、重连和重复提交都能正确收敛，不重复执行同一操作。
- [ ] 需要确认的动作显示审批卡片；允许、拒绝、超时和关闭审批均有明确结果。
- [ ] 停止生成/执行后服务端和客户端都停止，重新连接后不会继续执行旧请求。
- [ ] 文件读取、写入、导入和导出遵守工作区边界；路径穿越、未知操作和超时被拒绝并记录原因。
- [ ] Codex 与 DSH 各完成一条成功流和一条失败流，并保存对应日志证据。
- [ ] LAN IPv4、IPv6、错误地址、端口占用和设备切换均完成一次测试。
- [ ] Phone、Pad、PC 分别完成添加、配对、会话、审批、断线恢复和退出登录；大字体、软键盘和横屏布局无裁切。
- [ ] RustDesk AI 中继继续显示为未开放状态，不得被误认为已经可用。
