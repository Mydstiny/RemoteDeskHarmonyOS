## 1. 产品目标与现状

Pro 定位为鸿蒙跨设备协同、远程安全认证和高级工作体验。所有现有免费功能继续免费；今后用户明确指定为 Pro 的新增功能，统一登记到能力目录并绑定同一权益，不另建零散鉴权开关。

商业方案：一次性非消耗型购买，首发人民币 19.99 元、常规 28.88 元；实际结算以 AGC 商品返回的当地价格为准，不在客户端伪造价格。权益建议使用稳定标识 `pro.lifetime`；验证缓存的新鲜度不是永久权益的到期时间。

现有代码已提供设置页 Pro 入口、原生 bindSheet、预告权益、真实沙箱商品/下单/订单查询，以及权益服务和可信验证器的集成边界。沙箱商品已填写 `RemoteDesktop_Pro_Test`。尚无正式可信验单后端、完整恢复购买/退款闭环、已交付付费功能和真机购买成功证据；生产购买保持关闭。

### 1.1 免费与 Pro 的明确边界

| 范围 | 规则 |
|---|---|
| 现有功能 | 全部保持当前免费状态，不因改版收回 |
| 现有核心连接、画质、输入、文件传输、安全能力 | 继续免费；新增的碰一碰协同和安全密钥重定向按用户明确指定单独归入 Pro，不将底层已有能力收费 |
| 用户明确指定属于 Pro 的新功能 | 登记到统一 Pro 功能目录 |
| 未明确标注的新功能 | 默认免费，不擅自设为付费 |
| 尚未实现或未通过验收的功能 | 不出现在正式操作界面，不作为已交付权益销售 |

### 1.2 原始候选功能包

以下候选方向与后续补充的鸿蒙协同、认证、Logo 计划一并保留。P1/P2 是候选包内优先级，不替代第 11 节里程碑，也不代表已批准全部实施。

| 优先级 | 功能包 | 具体内容 |
|---|---|---|
| P1 | 工作区预设 | 保存主机组合、布局，一键打开常用工作环境 |
| P1 | 高级主机管理 | 智能分组、保存筛选条件、批量修改非敏感配置 |
| P2 | 个性化方案 | 多套工具栏、快捷键和外观方案，按主机应用；应用 Logo 另见第 9 节 |
| 后续 | 效率工具 | 命令模板、批量任务、备份历史等另行规划 |

实施前与现有免费能力逐项对照，避免将已有分组、命令、配置或文件功能重新包装收费；候选包保持 planned，具体收费范围须明确确认。

### 1.3 一次买断与后续版本

买断统一授予 `pro.lifetime`：已购买用户升级后，自动获得后续纳入同一 Pro 买断范围的已交付功能，无需再次购买。服务器确认是否拥有该买断权益，客户端功能目录决定本版本哪些功能属于 Pro，发布状态、应用版本和设备能力共同决定展示范围。

服务器不能仅返回购买当天的功能 ID 清单作为长期授权上限，否则新增功能容易遗漏老用户。未来如新增持续成本的托管中继、云存储等服务，应另行设计独立权益，不悄悄改变已售 Pro 的承诺。

## 2. 统一功能目录与鉴权

每个功能登记：稳定 featureId、权益要求、发布状态、最低应用版本、最低系统/API、设备类型、协议能力、必要权限与可用性原因。发布状态至少区分 planned、experimental、released、disabled。

建议首批目录如下；实际开发时核对现有目录并迁移命名，避免重复 ID：

| 功能 ID | 产品内容 | 发布前依赖 |
|---|---|---|
| `pro.file.knockTransfer` | 碰一碰传文件到当前远端位置 | Share Kit、协议文件通道、目标校验 |
| `pro.connection.knockShare` | 碰一碰分享连接 | 官方分享/协同通道、授权、连接状态恢复 |
| `pro.connection.continuation` | 同账号官方接续 | 系统接续、目标设备重连与回执 |
| `pro.security.webauthnRedirect` | RDP 安全密钥重定向 | RDPEWA、本地认证器、权限与 native 验证 |
| `pro.security.phonePasskey` | 华为手机通行密钥认证 | 官方跨设备认证路径端到端验证 |
| `pro.personalization.appIcon` | 应用 Logo 个性化 | API 26 备选图标；任意图片另设能力子条件 |

现有工作区、主机管理、个性化等预告保持 planned，待具体需求和验收标准明确后再拆成实际功能，不把预告视作已实现能力。

统一判断分为两部分：权益是否有效，以及当前环境是否具备执行能力。未知功能、未发布功能默认不可执行。UI 菜单、设置、快捷操作、深链入口和业务服务使用同一结果；不能只隐藏按钮而放行业务调用。

- 免费用户隐藏 Pro 专属功能入口，保留统一 Pro 介绍/购买入口。
- Pro 激活后，仅展示本版本已发布且适配的操作；能力介绍页可解释设备/协议限制。
- planned 功能只作为明确标注的路线图，不暗示付款即可立即使用。
- 购买、恢复、账号切换、退款撤权、调试切换后实时刷新各窗口；销毁窗口时解除订阅。
- 开始操作前重新鉴权；进行中撤权采用安全收尾策略，不因界面隐藏丢失文件或中断必要清理。
- 账号、环境、请求 generation 隔离；普通偏好设置与原始 IAP 返回值不能授予生产权益。

发布规则补充：可申请权限尚未授权与静态设备不支持分开判断；具备 Pro 与静态支持的用户可见授权入口，执行返回 permissionRequired，授权后再次检查。

### 2.1 显示状态与固定入口

| 用户/功能状态 | 实际界面 |
|---|---|
| 免费用户 | 隐藏 Pro 专属按钮、菜单、设置项和快捷操作，不到处显示锁图标 |
| 已激活 Pro | 显示当前应用版本已交付、当前设备支持的 Pro 功能 |
| 权益正在确认 | 使用仍符合缓存策略的可信缓存；没有可用可信缓存时按免费界面展示 |
| 已确认退款或撤销 | 收回 Pro 权限、隐藏入口，保留用户配置和数据 |
| 未发布或设备不支持 | 即使已激活 Pro 也不显示操作入口；介绍页可说明规划和限制 |

设置页底部 RemoteDesk Pro 栏位始终保留：免费用户进入介绍/购买页，Pro 用户进入权益详情/恢复购买页。未发布内容明确标为规划，不混入已拥有权益。

购买成功并完成验证后自动刷新，无需重启。隐藏项目不保留空白占位，不能被键盘焦点或无障碍导航选中；隐藏时正确转移已有焦点。

### 2.2 后续功能固定接入流程

声明示例（仅示意，名称与实际目录统一后使用）：

```text
功能 ID：workspace.savedLayouts
归属：Pro / pro.lifetime
发布状态：已交付（仅在实际验收后设置）
最低应用版本：对应发布版本
支持设备：Phone / Pad / PC
未授权显示方式：隐藏
入口：工作区菜单、快捷操作
```

统一策略分别返回“是否显示”和“是否允许执行”，并给出原因；同时考虑权益、发布状态、应用版本、设备及协议能力。以后新增用户指定的 Pro 功能按以下顺序执行：

1. 注册稳定功能 ID。
2. 声明 Pro 归属、发布版本和适用设备。
3. 页面接入统一显示组件。
4. 业务操作接入统一权限检查。
5. 增加免费/Pro 两种状态验收。
6. 验收通过后标记已交付。

不得在各页面散落独立 isPro 开关；直接跳转页面、深链接、快捷键、恢复旧工作区及任务恢复同样经过业务权限检查。

### 2.3 六模块架构

| 模块 | 职责 |
|---|---|
| 功能目录 | 定义功能、免费/Pro、发布版本和设备范围 |
| 真实权益服务 | 订单验证、账号绑定、恢复、撤销和可信缓存 |
| 调试权益控制器 | 提供三种测试视角，独立于真实权益 |
| 统一访问策略 | 计算显示、执行权限及原因 |
| 界面绑定组件 | 监听变化、显示/隐藏入口、管理焦点与过渡 |
| 购买协调器 | 商品读取、付款、验证、发货和异常恢复 |

```text
真实权益 ──┐
调试视角 ──┼── 统一访问策略 ── 界面显示
功能目录 ──┤                 └─ 业务执行检查
设备能力 ──┘
```

现有目录、策略和权益服务接口作为基础；上述统一显示控制、版本规则、调试层与真实订单验证仍须实施，不能将现有接口视为完整架构已交付。

## 3. 调试免费与 Pro 界面

Debug 专属入口提供三态：真实权益、模拟免费、模拟 Pro。生产包不包含可激活的模拟入口或持久化绕过路径。

模拟层与真实权益分离，切换立即更新主界面、设置、已打开弹层和多窗口；模拟 Pro 只改变产品权益判断，不绕过 API、设备、权限、认证来源或网络条件。模拟状态不得完成真实订单、污染正式缓存或被当成付款证明。验收包含退出模拟恢复真实状态、账号切换、应用重启策略及生产包不可启用模拟模式。

调试入口：设置 → RemoteDesk Pro → 开发者调试 → 权益模拟。

| 模式 | 用途 |
|---|---|
| 跟随真实权益 | 验证真实购买、恢复和账号行为 |
| 模拟免费用户 | 即使已购买，也展示免费界面 |
| 模拟 Pro 用户 | 无需付款，验证已实现 Pro 功能的界面和本地行为 |

切换后显示明显“模拟免费”或“模拟 Pro”标记。默认仅当前运行期间生效，重启回到“跟随真实权益”；退出模拟立即恢复真实状态，无需重新购买。关闭模拟 Pro 只改变测试视角，不退款、不删除配置、不清空用户数据。

正式发行包必须剔除模拟授权的可执行路径，不能仅隐藏按钮。模拟 Pro 不能绕过真实服务器鉴权；未来收费云服务通过测试环境或模拟数据验证。

## 4. API 26 基础 UI 升级与能力适配

2026-09-07 明确：公共 UI 升级是基础版本免费工作线，详见 [API 26 基础 UI 升级计划](2026-09-07-api26-base-ui-upgrade.md)。使用独立 U0–U4 里程碑，不纳入 Pro 权益清单、不依赖验单后端；以下新 API 同时涉及免费 UI 与另外明确指定的 Pro 功能，不能按 API 版本统一收费。

使用支持 API 26 的工具链评估编译升级，保留 API 23 兼容目标；具体编译配置在实施前验证，不在本次修改。API 26 接口通过适配层隔离，验证旧设备启动时不会因静态引用/模块加载崩溃；运行时检查版本、syscap、设备条件和接口返回。

本机 SDK 已确认：

- `harmonyShare.ReceivableTarget.getInfo()` / `SharableTarget.getInfo()` 自 26.0.0 提供可选 `coordinate`，包含 `screenX/screenY`，默认可能为 -1。
- `serviceInteraction` 自 26.0.0 提供 KNOCK 触发、windowId、App Linking、连接消息收发，要求 `ohos.permission.KNOCK_COLLABORATION`；准入及设备支持需验证。
- `bundleManager.setAlternateIcon/getAlternateIcons` 自 26.0.0 提供备选图标操作。
- ArkUI SDK 已有 `ComposeTitleBarV2`、`ComposeListItemV2` 等 API 26 组件；存在声明不等于已适合当前布局或已通过设备验证。

公共 UI 升级覆盖连接列表、设置页、标题栏、Pro 面板、远程工具栏和协同状态提示；基础升级面向所有用户，Pro 专属工作区和个性化操作才绑定权益。保持深浅色、Phone/Pad/PC、自适应窗口、键鼠/触屏、字体缩放与无障碍一致。沿用原生弹层和受控动画，避免材质影响远程画面识别与性能。

## 5. 碰一碰传文件到远端位置

目标：手机碰鸿蒙 PC 远程窗口，文件发送到该会话当前选中的远端目录；API 26 增强为碰点识别目标区域。

数据链路：官方接收 → 每次传输独立的本机暂存目录 → 文件类型/大小/数量检查 → 绑定远程会话与目标 → 协议传输 → 完成或失败回执 → 清理。

窗口注册绑定 windowId、sessionId 和 generation；后台、断连和销毁取消注册，迟到回调不能向另一连接投递。支持取消、磁盘不足、冲突命名、大文件流式传输与暂存清理；不把全文件强制读入内存。

API 26 坐标须经过屏幕到窗口、内容区、缩放/平移、远端显示器坐标变换。坐标不能自动推导远端文件系统目录；无坐标、无效坐标或无法确认目标时回退到当前窗口/明确选定目录，并提示用户确认。

| 协议 | 第一阶段路径 | 限制 |
|---|---|---|
| RDP | 文件剪贴板，在明确聚焦的文件管理器执行粘贴 | 受服务器策略与目标应用支持限制；不承诺任意窗口都可落盘 |
| SSH/SFTP | 上传到应用明确持有的当前远端目录 | 目标权限、覆盖与路径变化需要检查 |
| RustDesk | 核实现有文件通道，再扩展指定目录与大文件能力 | 旧调查中的固定目录/内存限制须以实施时代码重新核实 |
| VNC/Moonlight | 暂不发布通用文件落盘能力 | 标准会话没有可直接复用的通用文件通道；另行立项 |

先验证一个协议的选定目录闭环，再验证碰点增强，不以模拟接收代替实际远端文件完整性验证。

## 6. 碰一碰分享连接

目标：当前连接可通过官方碰一碰通道分享给对方手机，确认后直接进入并恢复支持的操作状态。

评估 Share Kit + App Linking，以及 API 26 ServiceCollaborationKit 消息通道；消息通道不是已确认的任意大文件通道。共享的连接描述需有版本号，携带协议、端点、显示/输入配置和可恢复状态；设备本地路径、句柄与临时会话密钥不得直接复制。

默认不分享密码、私钥、购买凭据或 Pro 权益。需要免重复输入时，设计用户明确授权、短时、一次性的安全邀请；接收端仍受远端服务器授权和网络可达性约束。接收方必须能识别协议与配置版本，未安装应用时给出官方跳转引导。

建议发起高级分享需要 Pro，接收方可使用现有免费连接能力；高级接续/安全能力在接收端独立鉴权。此接收侧权益策略属于产品建议，实施时确认，不把发送者权益转授给他人。

“无损”定义为已声明字段和工作上下文正确恢复；活动 socket、未完成传输、终端进程不默认可迁移。目标端确认连接与状态恢复完成后才按用户选择保留或退出源端，失败保留原连接。

## 7. 同账号官方接续

采用 HarmonyOS 官方应用接续，校验同华为账号、双方安装应用和系统协同条件。账号身份与本应用购买权益分别校验，不能用“同系统账号”替代验单。

与分享共用版本化连接状态恢复模型，增加接续事务 ID、目标就绪回执、超时与源端恢复。官方 onContinue 的 wantParam 数据需小于 100 KB，大数据使用官方建议的独立迁移方式；不迁移原生指针或网络连接对象。

保存协议、主机引用、远端显示器、缩放/平移、输入模式及可恢复的目录/页面状态；凭据通过已有可信存储或明确授权重新取得。RDP 桌面会话保留取决于服务端策略；SSH 持久工作需要 tmux 等远端会话机制，普通终端进程不承诺无损接续。重复请求、目标离线、版本不兼容、账号改变、网络切换都应可回退。

## 8. 远程安全认证

### 8.1 USB FIDO2 → RDP Windows 会话

复用原安全密钥调查范围：本地鸿蒙 PC/2in1 USB FIDO2 认证器，经 MS-RDPEWA 服务远端 Windows 会话内网站/应用认证。它不等于 Windows 登录解锁，也不覆盖智能卡/PIV/OTP或所有远程协议。

实施前重新核对 FreeRDP RDPEWA 构建、libfido2/libcbor、OHOS HID backend、HID DDK 权限与 ACL 准入；若增加依赖，同步 SBOM、NOTICE、provenance 和哈希。私钥留在认证器，PIN/触摸由本地安全交互处理；拔出、取消、断连能终止请求，不记录敏感认证材料。

### 8.2 远端请求 → 华为手机通行密钥

作为独立 Pro 功能与可行性原型。华为官方已有本地通行密钥与跨设备扫码认证能力，本机 `@hms.security.fido2` 定义属于 OnlineAuthenticationKit；不能据此推断应用能代理任意网站的认证请求。

先验证官方支持的跨设备路径与 RDP WebAuthn 的衔接，确保 RP ID、origin、challenge、用户确认及防重放语义正确。应用自身接入 FIDO2 的域名关联能力不能被用于冒充任意远端网站。

首阶段“设置/解锁”限定为支持网站/应用的通行密钥注册和认证；任意 Windows 登录界面解锁没有完成可行性证明，不作为购买承诺。成功标准是远端真实服务完成注册/认证，取消与断连正确传播且私钥始终不离开官方认证器；失败则保持 planned，不用自建不安全认证中转替代。

## 9. 应用 Logo 个性化

归入 `pro.personalization.appIcon`：默认 Logo 免费，切换我们随应用提供的预设 Logo 为 Pro；用户导入自定义图片也纳入 Pro 产品范围，但系统图标替换支持须单独验证。

已确认的 API 26 路径：在 AppScope/app.json5 的 alternateIcons 声明随包资源，通过 setAlternateIcon(name) 切换，getAlternateIcons() 查询，空名称恢复默认。接口要求名称匹配预声明项，因此不能承诺任意本地图片可直接作为系统应用图标。任意图片路径未通过验证前不展示成已交付权益；不能把仅修改应用内图片宣传为更换系统图标。

设置页提供预设网格、名称、预览、当前选中、应用反馈与恢复默认。恢复默认始终允许；权益明确撤销后阻止新增付费切换并允许恢复，系统已选图标的处理在实施时确定，不将短暂验单失败视为撤权。Debug 模拟免费优先验证 UI，避免自动改动真实系统图标。

验证桌面、Dock、最近任务、Ability/启动图标是否一致；对不能自动同步的场景如实说明。覆盖重启、应用升级、图标资源被移除、应用分身、Phone/Pad/PC，以及 API 23 不调用新接口的回退。

## 10. 正式购买与权益闭环

后端校验签名/发行方、应用、商品白名单、环境、身份、订单状态和新鲜度；服务端密钥不进入客户端或仓库。使用稳定订单标识保证幂等。

顺序：取得订单 → 可信验单 → 持久化权益 → 发布当前账号权益 → 完成发货确认。验证不可用时保持待处理，不提前 finishPurchase。恢复购买完整遍历订单分页及未完成订单；账号切换隔离旧回调。

支持带完整性保护的已验证离线缓存、退款/撤销通知及主动对账；规定离线宽限期和错误提示。短时网络失败不等于退款，永久权益不因验证缓存到期而被描述成订阅到期。

正式发布前须具备可用付费功能、真实商品与商户条件、准确权益描述、恢复购买、退款撤权和设备验收。具体后端部署、生产启用在后续实施任务中进行，本次计划落盘不代表上线授权。

### 10.1 账号、离线和运行中变化

- 账号切换立即隔离旧账号权益，旧请求返回不能授权给新账号。
- 已验证买断权益支持受控离线缓存，验证暂时失败不等于退款；缓存有效期表示重新验证时间，不是买断许可证到期。
- 已确认撤销后停止新的 Pro 操作，不突然中断免费的远程连接。
- 进行中的任务按功能安全退出或完成当前事务，避免直接取消造成数据损坏。
- 隐藏 Pro 功能后保留其配置，恢复权益后继续使用。
- 沙盒订单和模拟状态不能进入正式授权。
