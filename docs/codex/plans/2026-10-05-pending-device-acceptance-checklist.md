# 待验收清单（2026-10-05）

分支 `codex/pro-purchase-foundation` 上已经开发、但还没有在真机上验收的功能，留待之后统一验收。每一项都写了验收步骤和预期结果，验收完在「结果」栏填 ✅ / ❌（附现象），失败的项回到对应计划修复。

**通用前提**
- 安装当前分支的 Debug 包，保留数据安装（`hdc install -r`）。Release 包里的实验功能（手机通行密钥、安全密钥重定向）默认关闭。
- 清单编写时的版本：`0aa13c6f3`；Debug HAP 的 SHA-256 为 `5330c76b…7fce`，2026-10-05 已装到手机和平板。
- 设备：手机 SGT-AL10、平板 MLR-AL10、鸿蒙 PC。电脑端需要 Windows 11（RDP）和一台装好远程 AI 插件的电脑。
- 登录同一个华为账号。Pro 处于免费试用状态，或在调试面板里选择「模拟开启」。
- ohosTest 只编译，不在设备上运行（D-025）。

设备列缩写：手 = 手机，板 = 平板，PC = 鸿蒙 PC。
