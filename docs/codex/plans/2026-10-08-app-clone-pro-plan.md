# 应用分身的 Pro 权限

## 状态

- 2026-10-08 用户决定：先采用方案 B（已实施）；方案 A 记录在此，待真机验证后再做。
- 相关设计：`2026-08-28-harmonyos-app-clone.md`（分身为本地模式，不登录华为账号、不参与云同步）。

## 现状：Pro 如何判定

1. Pro 权益绑定在已登录的华为账号上：`ProAppRuntime.bindScope` 只在账号范围为 `huawei_account` 且会话可用时，取它的 `ownerScopeId` 作为权益所有者；购买是一次性（NONCONSUMABLE）商品，由服务端核验后签发权益，本机缓存并定期复核。
2. 分身（`getCurrentAppCloneIndex() > 0`）按设计不初始化 Account Kit，账号范围是本机范围，所有者为空：
   - 权益状态恒为 `free`；
   - `ProBillingService.capture` 拿不到购买租约，购买和恢复都在付款之前就失败（`Pro service unavailable`），不会扣费。
3. 1.2.0 免费试用（`PRO_COMPLIMENTARY_TRIAL = true`）期间，`free` 一律按 Pro 处理，所以分身现在也有全部 Pro 功能。
4. 试用结束后，分身永远拿不到 Pro，即使同一用户已在主应用购买。

## 方案 B（已实施）

试用结束后，分身里直接说明，不再给出一个必然失败的购买入口：

- Pro 状态文字显示「应用分身暂不支持 Pro」（`ProClonePolicy.proCloneLabel`，用在设置页、购买页和功能状态）。
- 购买页在分身中不显示购买和恢复按钮，改为说明：分身不能登录华为账号，因此无法购买或恢复 Pro，请在主应用中购买和使用。
- 试用期间购买页额外提示：试用结束后分身暂不支持 Pro。
- 功能状态「需要 Pro」的说明在分身中改为「应用分身暂不支持 Pro，请在主应用中使用」。

## 方案 A（待做）：分身只为 Pro 登录华为账号

目标：分身可以登录华为账号，仅用于 Pro 的购买、恢复与核验；仍不开放云同步、不共享主应用数据。

前置验证（真机，手机与平板各一台）：

1. 分身中 Account Kit 登录可用，并与主应用拿到同一华为账号的 unionID（权益所有者一致）。
2. 分身中 IAP Kit 可查询、购买、恢复同一非消耗型商品，订单归属同一账号。
3. 交叉登录、退出、撤权矩阵：任一实例登录或退出不会使另一实例的会话失效或数据丢失（2026-08-28 计划中的放行条件）。
4. 主应用已购买时，分身「恢复购买」能拿到同一份签名权益；退款或撤销在两个实例中一致生效。

实施要点：

- `AppClonePolicySnapshot` 增加 `proAccountAllowed`（分身为 true），与 `accountKitAllowed`（云同步、账号设置）分开；云同步入口保持拒绝。
- 分身登录入口只出现在 Pro 购买页，文案说明「仅用于 Pro，不会同步数据」。
- `ProAppRuntime.bindScope` 对分身使用该账号范围；权益缓存仍在分身自己的沙箱中。
- 去掉方案 B 的说明与按钮隐藏，或改为仅在分身未登录时显示。

放行条件：上述 4 项真机验证全部通过并有记录；独立复核通过。
