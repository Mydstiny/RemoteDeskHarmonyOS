## 有意保持开放的边界

`ProProductionRelease.RELEASE` 仍保持关闭且为空配置，连接分享基础域名也保持为空；这是为了避免在缺少正式华为后台参数、通知端点、域名关联和回归证据时误开启收费或外部入口。沙盒模拟权益只放行标记为 `experimental` 的能力，Release 路径不会接受模拟状态。

因此，当前剩余项主要是设备、账号、华为后台或协议外部条件，不能仅靠继续改客户端代码安全完成。若要进入正式发布验收，应先补齐这些外部条件，再按本记录逐项执行真机和跨设备验收。
