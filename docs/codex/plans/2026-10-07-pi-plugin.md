# 远程 AI：Claude Agent 插件改为 Pi 插件（2026-10-07）

## 为什么改

Claude Agent 插件要求用户另外提供 Anthropic API Key（Agent SDK 条款不允许第三方产品使用 claude.ai 订阅登录），实际用不起来。

[Pi](https://github.com/earendil-works/pi) 是开源的编程代理，有公开的 SDK。插件直接驱动用户电脑上已有的 Pi，沿用它的登录、模型和对话。电脑上的 pi-gui 也用同一份数据。

## 插件

- 仓库：Mydstiny/remotedesk-pi-plugin（由 Mydstiny/remotedesk-claudecode-plugin 改名）
- 版本：0.3.0
- 固定提交：a826216a559bd44508fa77f1ec08b36fc711a37e
- 引擎 id：`pi`；主机桥端口 9445（沿用原 Claude Agent 端口）；控制面板 127.0.0.1:9545
- 本机安装：`~/Library/Application Support/RemoteDesk/pi/0.3.0-<提交>`，状态目录 `~/.remotedesk/pi`，LaunchAgent `com.remotedesk.pi.*` 和 `com.remotedesk.panel.pi`
- 原 Claude Agent 服务和面板已停止并注销。状态目录 `~/.remotedesk/claudecode` 保留不动；面板的 LaunchAgent 移到了 `~/.remotedesk/claudecode/panel-launchagent.plist.disabled`。
- 停止服务要用 `remotedesk-pi.mjs stop --state ~/.remotedesk/pi`。Pi 的依赖带有 signal-exit：如果服务只用 `process.once` 监听 SIGTERM，监听被移除后 signal-exit 会重新发出真正的 SIGTERM，服务在释放锁之前就被杀掉，下次启动会提示需要 recover。插件已改为常驻监听，停止完成后再退出（a826216）。
- 接口与事件格式：插件仓库 `docs/protocol.md`

### 能力

- **对话**：列出 Pi 终端和 pi-gui 的对话，可以继续；新对话写入 Pi，pi-gui 里也能看到。没有标题的对话，用第一条提示的第一行作标题。
- **项目**：pi-gui 的工作区和所有有过 Pi 对话的文件夹都会自动成为 App 项目。邀请时需勾选「全部项目」。
- **模型**：模型列表就是 Pi 已登录的全部模型，带各自的思考等级和上下文窗口。新对话默认用 Pi 设置里的默认模型，没有就用最近一次对话的模型。
- **权限**：仿 Codex 三档，默认只读。由内联的 Pi 扩展在 `tool_call` 处拦截：
  - 只读：只给 read、grep、find、ls；
  - 修改前询问：bash 发 `command` 审批，edit/write 发 `fileChange` 审批（`engine: "pi"`，请求里带完整修改内容）；
  - 完全访问：全部直接执行。
- **其他**：
  - 中途可以插话、取消、压缩上下文、重命名，可以看 git diff；
  - 可以附带图片和文本；
  - 不加载用户或项目的 Pi 扩展。
- **与电脑同时使用**：另一个 Pi 界面对某个对话文件持有活跃租约（`<file>.lease`）时，手机只能查看这个对话，发送会返回 `PI_SESSION_OPEN_IN_APP`。

### 已在电脑端验收（真实模型，模拟主机桥核心；通过 mTLS 测试客户端读取）

- 只读：写入被拒，因为没有写工具。
- 修改前询问：编辑和命令各批准一次后执行成功；拒绝命令后，模型说明原因并停止。
- 取消运行中的 `sleep 30` 后，下一轮正常。
- 服务通过 mTLS 返回 `project.list`（pi-gui 工作区）、`session.list`（电脑上的对话，origin=computer）、`session.read`（历史、模型、上下文用量）、`model.list` 和 `handshake`（engine=pi、三档权限）。

## App 端

- 后端 id 由 `claudecode` 改为 `pi`，显示名为「Pi」，副标题为「Pi 编程代理 · 9445」。Pro 功能 id 改为 `pro.ai.pi`。
- **迁移**：
  - 本地保存的 `claudecode` 主机读出时视为 `pi` 主机，旧配对凭据作废，需要重新配对；
  - 默认后端和导入的备份同样迁移。
- **复用事件解析**：原 Claude 事件解析器改名为 `aiAgentItems`；`aiAgentEvents(backend)` 决定哪些后端用这套解析。
- **审批**：Pi 的 `fileChange` 审批直接显示请求里的修改内容。
- **权限文案**：新增「修改前询问」「完全访问」。Pi 的只读说明为「只能查看和搜索文件，不能运行命令或修改文件」。
- **错误码**：新增 `PI_SESSION_OPEN_IN_APP`、`PI_NOT_INSTALLED`、`PI_SESSION_NOT_FOUND`、`PI_INITIALIZATION_FAILED` 的中文说明。
- **安装引导**：指向 Pi 插件的固定提交。
- **AI 助理**（知识库 v17）：
  - 说明 Pi 后端、「全部项目」授权、对话列表与聊天页、模型和权限选择、pi-gui 同时打开时的限制；
  - 更新主机、安装、显示相关的动作关键词。
