# RemoteDesktop 用户使用文档

更新日期：2026-09-04

## 一、应用简介

RemoteDesktop 是面向 HarmonyOS NEXT 的原生远程连接工具。1.1.5.1 当前可使用 RDP、RustDesk、SSH/SFTP、VNC 和 Moonlight；同时提供密钥库、TOTP 验证器、华为云同步、本地备份、后台视频、画中画以及手机、平板和 PC 响应式界面。实际连接质量取决于远端服务、网络、系统权限和设备能力。

从 1.1.5 更新安装后，1.1.5.1 的变化只会在第一次进入新版本时自动展示一次；新安装应用会显示按步骤编排的新用户 Swiper。当前更新说明不超过 14 页，在手机使用底部 Sheet、在平板和 PC 使用居中 Sheet；首次安装教程直接作为页面首屏显示，并在内容异常时提供可见兜底，避免冷启动白屏。两套内容之后都可从设置页重新查看。

## 二、首次使用

1. 阅读首次启动功能介绍，了解连接、输入、传输、同步和安全能力。
2. 选择华为账号登录或离线使用。离线模式的数据只保存在当前设备。
3. 如需跨设备同步，请登录华为账号，并按设置页提示完成云服务前置条件。
4. 如需保护密钥、凭据和验证器数据，请设置并妥善保存主密码。主密码丢失后无法恢复已加密数据。
5. 教程可从“设置 → 教程”随时重新打开；需要重复显示会话内提示时，可开启“始终显示引导”。

## 三、添加和管理主机

在主机页点击添加按钮，按场景选择连接方式：

1. RDP：适合连接已开启远程桌面的 Windows 专业版或企业版设备。填写主机地址、端口、Windows 凭据和显示配置。
2. RustDesk：适合跨平台远程控制。填写远程设备 ID 和密码；使用自建服务时，先配置 ID、Relay 和密钥信息。
3. SSH：适合服务器终端维护，支持密码、私钥和跳板机。首次连接前请核对服务器主机指纹。
4. SFTP：建立 SSH 会话后，从顶部文件入口浏览和管理远端文件。
5. VNC：从主机页添加按钮进入 VNC 配置，可填写目标地址、端口、安全策略以及可选网关。首次连接和跨设备恢复后，应重新核对服务器身份与本机信任提示。
6. Moonlight：适合连接已部署 Sunshine 的主机。先发现或手动添加主机，核对身份并完成 PIN 配对，再从应用目录选择要启动的项目。

主机可按工作组整理并按协议筛选。界面展示的剪贴板、文件传输等能力以当前真实会话状态为准；尚未就绪时会说明原因。

## 1.1.5.1 更新内容（相对 1.1.5）

1. 鸿蒙 PC 画面翻转：Moonlight 增加与 RustDesk 一致的手动画面翻转兜底，并深化硬件解码变换诊断。
2. RDP 连接凭据与断线归因：可选择不保存账户和密码、每次连接时输入；只有服务器实际发送 ErrorInfo 才归因为服务器错误，客户端或网络失败不再默认误报为 0x10。
3. RDP 全屏鼠标：修正 PC 全屏模式下输入只能映射到左上角区域的问题。
4. RustDesk 工具栏：补充可操作的二级菜单，并在鼠标悬停按钮时显示名称。
5. RustDesk 编解码选择与监控：修复预鉴权连接遗漏 H.265 偏好的问题，并按当前会话真实生效的编解码器和后端更新监控状态。
6. RDP 分辨率缩放：对齐控制端窗口、远端桌面尺寸、动态布局和显示缩放，减少比例错误与大黑边。
7. Dock 输入保护：鸿蒙 PC 最小化和恢复窗口时封锁残留指针事务，避免误触远端右键。
8. SSH 常用命令：在“更多”中新增可编辑、删除并可随时调用的常用命令。
9. 退出保护：可关闭远程会话快捷退出，启用后只能通过明确按钮退出，并保留顶栏或侧栏。
10. RustDesk 文本剪贴板：补全远端到本机的接收、权限和防回环路径，实现双向复制粘贴。
11. 经典主机列表：增加底部滚动安全区，避免最后一张主机卡被悬浮按钮遮挡。
12. 鸿蒙快捷键：键盘设置新增简化后的设备分类开关和图标，明确“打开即屏蔽”；PC 默认屏蔽并持久化保存。

## 1.1.5 更新内容（相对 1.1.4）

1. 分协议画面控制：RDP、RustDesk、VNC 与 Moonlight 可分别保存双指缩放偏好，并从会话控制区恢复画面状态。
2. RustDesk 质量与多显示器：会话可选择低延迟、均衡或最佳质量；HarmonyOS PC 可在实验多画布模式中同时查看最多两块远端显示器，并在异常时回退单画布。
3. RDP 高 DPI：PC 端结合活动显示器密度、窗口尺寸和方向请求合适的远端画面，跨屏或动态显示控制不可用时保留兼容回退。
4. 连接恢复与诊断：网络切换会淘汰过期连接任务，Moonlight 添加入口不再被可选探测临时置灰；诊断导出可记录脱敏 IPv4/IPv6 地址族与作用域，不包含原始地址。

## 1.1.4 更新内容（相对 1.1.3）

1. 敏感信息保护：可在“数据与安全”按凭据类型决定是否显示已保存密码；隐藏状态下编辑其他主机信息会保留原密码。
2. 剪贴板与分身：RDP、RustDesk、VNC 连接后即可激活文本剪贴板；支持的手机和平板可创建一个本地隔离、默认不启用云同步和自动剪贴板的应用分身。
3. RustDesk 手机控制：修正横竖屏、纹理方向、缩放和触控坐标，统一释放异常中断后的残留输入。
4. 会话界面：图形协议键盘侧栏可统一打开和关闭，新增 Delete 编辑键；自定义快捷键编辑器适应横屏、分屏和 PC 窗口，移动端沉浸栏与设置折叠区域恢复更可靠。
5. 云数据恢复：权限竞争或可选历史迁移失败时保留同账号本地数据可用性，恢复时保护离线修改、删除与清空语义。
6. RustDesk 桌面翻转：HarmonyOS PC 可按主机选择仅翻转画面、画面与控制一起翻转或重置，并在重连和窗口恢复后沿用。
7. 独立滚轮方向：RDP、RustDesk、SSH、VNC 和 Moonlight 可分别设置正常或反向滚动，SFTP 文件列表保持系统方向。

## 1.1.2 更新内容（相对 1.1.1）

1. 五协议工作台：Moonlight 加入统一主机工作台，支持 Sunshine 发现或手动添加、身份核对、配对、应用目录、启动和独立设置。
2. Moonlight 会话：接入画面、声音、键鼠、触控和控制器输入，并区分重连、画中画、前后台恢复、仅断开与结束主机应用。
3. SSH 工作台：新增多标签、多窗格、侧栏、检查器与状态栏；手机保持单任务路径，宽屏可并行处理多个终端。
4. SSH/SFTP 工具：补充搜索、常用命令、广播输入、配置档案、快捷键、端口转发、双栏文件工作区和传输中心。
5. 会话输入：RDP、RustDesk、VNC 与 Moonlight 共用远程键盘入口，可切换 Windows/macOS 键位并发送功能键、导航键和自定义组合键。
6. 局域网与安全：RDP/RustDesk 可发现局域网主机并选择固定或动态地址策略；主机锁、RDP 证书、VNC TLS/明文与凭据在进入会话前统一确认。
7. 自适应引导：新用户 Swiper 按手机、Pad、PC 说明协议选择和操控方式；会话内提示默认只显示一次，可在设置中开启“始终显示引导”。
8. 数据与诊断：Moonlight 本地记录、备份、可选同步和配对信任保持清晰边界，诊断采集可脱敏导出，失败阶段与恢复结果更明确。

## 四、远程控制与输入

RDP、RustDesk、VNC 和 Moonlight 支持按协议能力使用触控板、直接触控与键鼠控制。手机和平板可使用触控手势，PC 更适合物理键盘鼠标；会话贴边入口可打开系统键盘、功能键和自定义快捷键。SSH 终端使用独立的输入、焦点和快捷键体系。

系统输入法支持中文、Emoji 和大段文字，并按输入顺序发送到远端。远程输入仍受目标系统、应用和当前协议能力影响。

## 1.0.9 更新内容

1. 账号级数据隔离：离线模式与每个已验证华为账号使用独立本地数据库，账号切换会停止旧同步任务并清理敏感缓存。
2. 云同步故障安全：首次拉取、重新启用、重试、超时和迟到回调统一进入持久化状态机；无法确认账号或数据形态时停止同步，避免错误覆盖。
3. 加密生命周期修复：加密启用、解锁、关闭和重置通过独占租约与可恢复状态推进，中断后不会静默进入半完成状态。
4. 本地备份 v3：新增账号绑定、完整性清单、事务恢复和旧备份按兼容表部分恢复；登录令牌、密码、私钥、TOTP 密钥与设备信任默认不导出。
5. VNC 旧数据隔离：只有归属、重置代次和数据形态均可验证的旧记录才会迁移，其余记录会进入脱敏隔离并保留原来源表供诊断。

## 五、文件传输与剪贴板

- SFTP 支持文件浏览、上传、下载、新建目录、重命名和删除。
- 上传或下载开始后，传输状态区域会提供取消操作。
- 保留在远端的部分上传文件可按已确认位置安全续传。
- RDP 通过共享目录提供文件访问；RustDesk 按当前会话能力提供文件传输。
- RDP 与 RustDesk 支持双向纯文本剪贴板同步，并包含长度限制和回环保护。
- Moonlight 面向低延迟音视频与输入串流，不提供远端文件传输；文件操作请使用 SSH/SFTP、RDP 共享目录或协议明确支持的入口。

文件能力只有在远端协议确认后才会显示为可用，连接成功并不代表所有可选能力都已经就绪。

## 六、密钥库、2FA 与隐私保护

密钥库用于保存 SSH 私钥，2FA 验证器用于保存 TOTP 一次性验证码。添加 2FA 时可扫描二维码，也可手动输入标准 `otpauth` 信息。

设置页可以启用验证器隐私保护和主机安全锁。敏感数据使用本地主密码派生密钥进行 AES-256-GCM 加密；请勿把主密码、私钥、验证码种子或备份文件发送给他人。

## 七、云同步、离线与本地备份

登录华为账号后，可以选择需要同步的数据类型。云同步会检查必要前置条件，并提供失败重试、下载回滚和异常恢复。启用并解锁应用加密时，受保护的敏感字段会在本机加密后上传；未启用时，用户明确选择保存和同步的部分凭据可能以未加密形式保存或同步，相关设置会提示风险。导入本地备份后必须明确选择一次“上传本机”或“下载云端”，仅勾选的数据会传输，未勾选的数据会保留在本机。

离线模式不会把业务数据上传到云端。本地备份支持导出数据、导入前预检和事务恢复：无效备份不会覆盖现有数据，恢复失败时会回滚。备份可能包含敏感信息，应存放在可信位置。

## 八、后台视频与多设备界面

远程会话支持后台连接、系统媒体播控和返回应用后的画面恢复；有真实视频且设备支持时，系统会显示画中画窗口。媒体胶囊和画中画由系统能力、用户开关和设备类型决定，不支持时仍保留连接/通知降级路径。手机使用适合触控的布局，平板和 PC 使用更宽的响应式布局。

后台能力可能受系统电量策略、窗口状态和设备权限影响。长时间离开后如远端已断开，请按界面提示重新连接。

## 九、反馈与畅联群聊

打开“设置 → 反馈”，可在两个入口间切换：

1. 邮箱反馈：用于提交问题、建议和必要的非敏感复现信息。
2. 加入畅联群聊：在线获取当前有效的群聊二维码，加载失败时可重试，加载成功后可保存到系统相册。

群聊二维码通过 HTTPS 清单更新并设有有效期。请勿在邮件或群聊中发送密码、主密码、私钥、TOTP 种子、真实主机地址或完整数据库备份。

## 十、常见问题

1. 无法登录华为账号：确认当前应用签名、包名和 AppGallery Connect 配置匹配，并检查网络和账号状态。
2. RustDesk 连接失败：先确认服务器配置是否已显示“保存到本机”，再核对 ID/Relay、公钥或共享 Key、连接 profile 和远程设备状态。地址簿登录成功只证明 HTTP 控制面可用，不等于 relay 已授权；请记录界面显示的阶段、错误码和尝试编号，切勿发送密码、令牌、完整公钥/共享 Key、账号或服务器地址。
3. RDP 登录失败：确认 Windows 已开启远程桌面，系统版本支持作为服务端，并核对本地、域、Microsoft 或 Azure AD 账号格式。
4. SFTP 看不到取消按钮：确认当前确实存在进行中的上传或下载，并查看文件面板的传输状态区域。
5. 剪贴板没有同步：确认设置中启用了对应协议的文本剪贴板，并等待会话能力显示为就绪；当前只同步纯文本。
6. 忘记主密码：主密码无法找回，只能重置加密并清空无法解密的相关数据。
