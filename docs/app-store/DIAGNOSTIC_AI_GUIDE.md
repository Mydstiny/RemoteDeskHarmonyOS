# RemoteDesktop 诊断与 AI 帮助说明

本文是 Pro 功能的操作、隐私和数据安全说明，和应用内的逐步提示保持一致。

## 使用流程

1. 打开“设置 → 诊断与 AI 帮助 → 辅助 AI 配置”。选择 Provider，确认区域和隐私摘要，填写请求地址、API Key 和模型 ID。优先使用中国大陆 Provider 或本机 Ollama；OpenAI 等国际 Provider 后续按同一适配器合同加入。
2. 保存后可以拉取模型列表。拉取失败时保留原配置，不会把 API Key 写入错误信息或普通日志。删除 Provider 会同时删除它在本机安全存储中的密钥。
3. 在“启动 AI 辅助”中描述问题。助手先展示预计采集的模组、时长、当前协议和停止方式。用户点击开始后，采集器只允许白名单模块写入脱敏事件，并以 captureId、schemaVersion、模块、事件码、耗时、结果码和统计值组成结构化包。
4. 结束采集后，助手把问题、知识版本和脱敏事件包发给所选 Provider，使用非流式、有限大小的请求。结果必须包含结论、严重程度、置信度、证据引用、未知项和只读建议；无法确认的内容显示为未知，不由客户端补猜。
5. 如果需要反馈，用户点击“生成邮件草稿”。草稿会包含主题、问题、结果、只读建议和脱敏事件包，系统邮件界面允许再次修改或放弃。发送完全由用户触发。

## 数据边界

- API Key、授权头和密钥指纹只存放在系统 Asset Store；Preferences 只保存 Provider、模型、地址和删除所需的引用元数据。
- AI 诊断包默认不包含屏幕像素、剪贴板正文、远程文件、密码、私钥、TOTP、API Key、完整 IP/域名和完整输入文本。网络事件使用地址族、作用域和脱敏阶段等字段。
- 采集有时长和大小上限，停止、超时、账号切换、退出、Pro 失效或页面销毁都会终止活动状态；诊断助手不会在后台静默抓取。
- 只有用户选择的 Provider 会收到请求。大陆 Provider、本机 Provider、跨境 Provider 和自定义地址在 UI 中标注区域；Provider 自身的留存、训练和跨境规则仍需用户阅读其政策。
- 配置不进入主机云同步、备份或应用诊断日志。切换账号时会撤销正在使用的密钥引用并隐藏常驻入口；恢复后需重新确认配置。

## 安全与失败处理

- 只允许 HTTPS；本机 Ollama 才允许回环 HTTP。默认拒绝带用户名、密码、查询参数、片段和未允许的自定义内网地址，禁止自动跟随重定向。
- API 响应有大小、模型数量和请求超时上限；错误信息只保留状态和可公开的短描述，不回显授权头或响应原文。
- AI 提议的设置必须匹配应用白名单，包含当前值、拟修改值、原因、证据和回滚值，并在用户确认后才能进入设置流程。命令执行、脚本、连接凭据修改和静默批量变更不属于助手权限。
- 助手不能替代协议、网络或服务商的最终判断。用户应以证据、应用提示和远端服务状态为准。

## 支持矩阵和验收边界

首批可用适配器覆盖 DeepSeek、通义千问、智谱、Kimi、硅基流动和本机 Ollama；豆包、文心一言、讯飞星火已进入 Provider 目录但明确标为“后续适配”，当前不会被选择或保存。实际请求地址和模型能力以服务商公开接口为准，发布前必须逐家完成官方文档、限流、错误码和隐私政策复核。OpenAI 等国际 Provider 留在后续阶段。

代码编译、HAP 打包和策略测试只能证明客户端链路正确，不能代替真实 API Key、Provider 网络、系统邮件、Pro 权益、设备动画或远程主机的验收。发布前需要在 HarmonyOS Phone/Pad/PC 上完成开关、账号切换、权限撤回、抓取停止、失败重试和邮件放弃矩阵。
