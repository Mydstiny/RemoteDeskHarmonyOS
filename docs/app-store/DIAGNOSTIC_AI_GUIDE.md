# RemoteDesktop 诊断与 AI 帮助说明

本文是 Pro 功能的操作、隐私和数据安全说明，和应用内的逐步提示保持一致。

## 使用流程

1. 打开“设置 → 诊断与 AI 帮助 → 辅助 AI 配置”。选择 Provider，确认区域和隐私摘要，填写请求地址、API Key 和模型 ID。优先使用中国大陆 Provider 或本机 Ollama；OpenAI 等国际 Provider 后续按同一适配器合同加入。
2. 保存后可以拉取模型列表。拉取失败时保留原配置，不会把 API Key 写入错误信息或普通日志。删除 Provider 会同时删除它在本机安全存储中的密钥。
3. 在“启动 AI 辅助”中描述问题。助手先展示预计采集的模组、时长、当前协议和停止方式。用户点击开始后，采集器只允许白名单模块写入脱敏事件，并以 captureId、schemaVersion、模块、事件码、耗时、结果码和统计值组成结构化包。
4. AI 也可以直接回答应用用法、隐私和安全问题，或给出打开设置页的操作卡；涉及日志时先征得同意。结束采集后，助手把问题、知识版本和有界的脱敏事件包发给所选 Provider。结果必须包含结论、严重程度、置信度、证据引用、未知项和只读建议；无法确认的内容显示为未知，不由客户端补猜。
5. Provider 请求失败时，脱敏诊断包会保留在本机，重新打开“启动 AI 辅助”可以点击“重试分析”或主动丢弃，不会因为页面重建而丢失。
6. 每次完成问答都会保存一个账号隔离的本机会话；“AI 会话管理”单独列出最近会话，点击任意会话会打开自适应对话框，并恢复该会话原来的 Provider、模型和上下文继续提问。“AI 用量监控”按 Provider+模型显示请求数、Token、缓存命中率和费用估算，并允许切换下一次请求使用的已配置订阅。助手名称、语气和用户主动填写的本地偏好位于独立的“AI 个性化设置”，只保存在本机。
7. 如果需要反馈，用户点击“生成邮件草稿”。草稿会包含主题、问题、结果、只读建议和脱敏事件包，系统邮件界面允许再次修改或放弃。发送完全由用户触发。

## 数据边界

- API Key、授权头和密钥指纹只存放在系统 Asset Store；Preferences 只保存 Provider、模型、地址和删除所需的引用元数据。
- AI 诊断包默认不包含屏幕像素、剪贴板正文、远程文件、密码、私钥、TOTP、API Key、完整 IP/域名和完整输入文本。网络事件使用地址族、作用域和脱敏阶段等字段。
- 采集有时长和大小上限，停止、超时、账号切换、退出、Pro 失效或页面销毁都会终止活动状态；诊断助手不会在后台静默抓取。
- 只有用户选择的 Provider 会收到请求。大陆 Provider、本机 Provider、跨境 Provider 和自定义地址在 UI 中标注区域；Provider 自身的留存、训练和跨境规则仍需用户阅读其政策。
- 配置、会话、用量和助手偏好不进入主机云同步、备份或应用诊断日志。API Key 仍只放在系统 Asset Store；切换账号时会撤销正在使用的密钥引用并清理账号隔离的本地 AI 数据。
- Pro 账号的 AI 入口在主机列表和远程会话右上角常驻显示，不再提供隐藏入口的用户开关；撤销 Pro 权益后入口按权益生命周期立即隐藏，传统日志仍可使用。
- 多个 API 配置互相隔离：每个 Provider+模型有独立的密钥引用、会话用量和费用估算；“当前 AI 订阅”只决定后续新请求，不会改写历史会话的归属。

## 安全与失败处理

- 只允许 HTTPS；本机 Ollama 才允许回环 HTTP。默认拒绝带用户名、密码、查询参数、片段和未允许的自定义内网地址，禁止自动跟随重定向。
- API 响应有大小、模型数量和请求超时上限；错误信息只保留状态和可公开的短描述，不回显授权头或响应原文。
- AI 提议的设置必须匹配应用白名单，包含当前值、拟修改值、原因、证据和回滚值，并在用户确认后才能进入设置流程。命令执行、脚本、连接凭据修改和静默批量变更不属于助手权限。
- 设置页、协议页和远程会话工具栏都通过动作注册表提供入口。普通导航使用执行胶囊，日志和长任务使用悬浮球，断开、凭据、文件传输、隐私和安全操作必须二次确认。
- Provider 响应中的 `appActions` 只能使用注册表 ID；未知动作会被丢弃。`execute` 用于设置页导航，`floating` 用于日志/长任务，`inline` 用于会话轻量开关；新增功能必须同时登记动作 ID、现有回调、知识步骤和三端 UI 验收。
- `settingProposals` 只能使用应用设置白名单中的可回滚布尔项（协议音频/剪贴板/驱动器、诊断显示、输入与显示手势、沉浸光感等），应用会先比较实时 `AppStorage` 值再写入；凭据、密钥、地址、TLS、代理和支付只提供导航或人工操作。
- 助手不能替代协议、网络或服务商的最终判断。用户应以证据、应用提示和远端服务状态为准。

## 支持矩阵和验收边界

首批可用适配器覆盖 DeepSeek、通义千问、智谱、Kimi、硅基流动和本机 Ollama；豆包、文心一言、讯飞星火已进入 Provider 目录但明确标为“后续适配”，当前不会被选择或保存。实际请求地址和模型能力以服务商公开接口为准，发布前必须逐家完成官方文档、限流、错误码和隐私政策复核。OpenAI 等国际 Provider 留在后续阶段。

代码编译、HAP 打包和策略测试只能证明客户端链路正确，不能代替真实 API Key、Provider 网络、系统邮件、Pro 权益、设备动画或远程主机的验收。发布前需要在 HarmonyOS Phone/Pad/PC 上完成开关、账号切换、权限撤回、抓取停止、失败重试和邮件放弃矩阵。

## 独立设置项

- **AI 会话管理**：查看最多 50 个账号隔离的本地会话；每个会话显示轮数和最近更新时间，点击后在弹窗中继续对话，并沿用会话记录的 Provider、模型和上下文。
- **AI 用量监控**：查看全部订阅汇总，或筛选单个 Provider+模型；显示请求次数、输入/输出 Token、缓存命中率、估算费用和当前用于新请求的订阅。Provider 没有返回真实账单时，费用只标注为估算。
- **AI 个性化设置**：设置助手名称、均衡/温和/简洁/技术语气、简洁/标准/详细回答长度、远程桌面专家/新手引导/排障优先/隐私优先角色、中英文回答语言，开启或关闭主动建议、敏感操作确认和本地记忆，并编辑或清除用户画像摘要。关闭记忆后，摘要不会附加到新请求；删除账号或清理 AI 数据会一并删除本地会话与画像。
- 个性化页是自适应滚动弹窗：手机使用底部弹窗，Pad/PC 使用居中弹窗，内容超过可用高度时在弹窗内部滚动，不会截断设置项。
- **订阅切换**：在“辅助 AI 配置”保存多个 Provider 后，可在“AI 用量监控”直接选择当前订阅；切换只影响后续请求，已有对话继续使用其原始会话记录和 Provider 统计。
