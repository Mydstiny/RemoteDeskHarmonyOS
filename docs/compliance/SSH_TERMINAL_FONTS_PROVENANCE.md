# SSH terminal font provenance

Bundled for the Pro SSH terminal skins (`entry/src/main/resources/rawfile/ssh-terminal/fonts/`).

- Source: npm packages `@fontsource/jetbrains-mono`, `@fontsource/fira-code`, `@fontsource/source-code-pro`, `@fontsource/ibm-plex-mono`, `@fontsource/cascadia-code`, `@fontsource/roboto-mono`, `@fontsource/inconsolata`, `@fontsource/victor-mono`, `@fontsource/fira-mono`, `@fontsource/geist-mono`, `@fontsource/space-mono`, `@fontsource/red-hat-mono`, `@fontsource/martian-mono`, `@fontsource/anonymous-pro`, `@fontsource/commit-mono`, all version `5.3.0`, fetched from
  `https://cdn.jsdelivr.net/npm/@fontsource/<family>/files/` on 2026-09-30 and 2026-10-01 with the user's approval.
  Only the Latin subset in weights 400 and 700 (`woff2`) is shipped, unmodified.
- Upstream projects: JetBrains/JetBrainsMono, tonsky/FiraCode, adobe-fonts/source-code-pro, IBM/plex, microsoft/cascadia-code, googlefonts/RobotoMono, googlefonts/Inconsolata, rubjo/victor-mono, mozilla/Fira, vercel/geist-font, googlefonts/spacemono, RedHatOfficial/RedHatFont, evilmartians/mono, Mark Simonson, eigilnikolajsen/commit-mono.
- License: SIL Open Font License 1.1 (`OFL-1.1`) for every family. Each family's copyright and license text is kept next
  to the files as `<family>-LICENSE.txt`; the plain license text is also in `LICENSES/OFL-1.1.txt`. The files are
  unmodified, so no Reserved Font Name is used for a modified version.
- Use: loaded only by the local terminal WebView through `@font-face`; nothing is fetched at runtime.
