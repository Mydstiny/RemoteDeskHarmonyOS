# SSH terminal font provenance

Bundled for the Pro SSH terminal skins (`entry/src/main/resources/rawfile/ssh-terminal/fonts/`).

- Source: npm packages `@fontsource/jetbrains-mono`, `@fontsource/fira-code`, `@fontsource/source-code-pro`,
  `@fontsource/ibm-plex-mono`, all version `5.3.0`, fetched from `https://cdn.jsdelivr.net/npm/@fontsource/<family>/files/`
  on 2026-09-30 with the user's approval. Only the Latin subset in weights 400 and 700 (`woff2`) is shipped, unmodified.
- Upstream projects: JetBrains/JetBrainsMono, tonsky/FiraCode, adobe-fonts/source-code-pro, IBM/plex.
- License: SIL Open Font License 1.1 (`OFL-1.1`). Each family's copyright and license text is kept next to the files as
  `<family>-LICENSE.txt`; the plain license text is also in `LICENSES/OFL-1.1.txt`. Reserved font names are not used
  for any modified version (the files are unmodified).
- Use: loaded only by the local terminal WebView through `@font-face`; nothing is fetched at runtime.
